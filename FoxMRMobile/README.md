# Fox MR Mobile
- `tracker/`  Android library: camera hand tracking (MediaPipe) + color tracking, presets, smoothing without prediction.
- `app/`      Fox MR test app: tracking settings, color calibration, PS4/Xbox/Nintendo controller calibration, side-by-side test view with head gyro.
- `unity/FoxMR/` Unity package for games (scripts + the built tracker library).
Build everything online: push this folder to a GitHub repo; the Actions tab builds the APK and the Unity package.
Not compiled or run on a device here. Only games you own or have written permission to modify.
